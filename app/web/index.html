    設定
    

    
    
      
      
      
      
    
    

    
    
      
      
      
      
    使えるトークン: {title} {artist} {group} {series} {id} {site} {pages} {lang}
    
      
      
    
    

    
    
      
      
      
    並列数はサイトごとの上限で自動的に抑えられます（pixiv は 2 並列・1秒間隔）。
    
      
      
      
      
      
      
      
    
        コピーしたURLがどのサイトにも一致しない場合、yt-dlpの汎用抽出器で取得を試みます。
        ここに列挙したドメイン(カンマ区切り、完全一致。サブドメインは別ドメインとして
        区別するので、必要なら www.example.com のように個別に書きます)はその対象から
        外します。手動でURLを貼り付けたときはこの除外リストの影響を受けません。
        汎用抽出器での取得が実際に失敗すると、そのドメインは自動でここに追加されます。
      
    
      
      
    
        汎用抽出器での取得に実際に成功したドメインが自動で溜まります。ここにあるドメインは
        上の除外リストに載っていても優先して拾います。
      
    
      
      
    
    

    
    
      
    動画の保存先
        
        
      
    
      
    音声の保存先
        
        
      
    
      
    PDFとは別のフォルダに保存します。空欄にすると既定の場所に戻ります。
    

      
    Cookie ファイル（任意）
        
        
      
    
      
    
        年齢制限・非公開設定などログインが必要な動画（X/Twitter など）の取得に使います。
        ブラウザの拡張機能（例: Get cookies.txt LOCALLY）でエクスポートした cookies.txt を指定してください。
      
    

      
      
      
      
      
    
        再生リストのURLでも1本だけ取得します。動画の結合と音声への変換には
        ffmpeg が必要です（winget install Gyan.FFmpeg）。無い場合は結合の要らない
        形式だけを取得し、音声の取り出しは失敗します。変換中は中止できません。
      
    
    
    

    
    
      
      
    指定形式が無いページは自動でもう一方にフォールバックします。
    
      
      
    
        R-18 作品や非公開作品の取得に必要です。ブラウザで pixiv にログインした状態で
        DevTools → Application → Cookies から PHPSESSID の値をコピーしてください。
        うごイラは PDF 化できないためスキップされます。
